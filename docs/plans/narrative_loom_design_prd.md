# PRD: Narrative Loom Design System

## Project Vision
Create a professional, high-tech interface for managing and monitoring a complex AI narrative generation pipeline. The design should feel "agentic," transparent, and powerful.

## Target Audience
- Narrative Designers
- AI Engineers
- World Builders

## Key Screens to Design
1. **Loom Workshop Dashboard**: Central hub showing pipeline throughput, active tasks, and system health metrics.
2. **Pipeline Execution View**: A real-time visualization of the LangGraph flow, showing each node (Engine/Agent) as it processes, with status indicators (start/done/error) and duration metrics.
3. **Narrative Studio**: Interface for submitting raw chronicles and reviewing the final output (Prose, Storyboard, Visual Configs).
4. **AI Configuration**: Management interface for LLM routing, agent parameters, and epistemic layer settings.

## Design Goals
- **Real-time Feedback**: Use Centrifugo events to create a dynamic, living interface.
- **Technical Transparency**: Make the complex multi-stage pipeline easy to understand and debug.
- **Epic Aesthetic**: The UI should reflect the "epic novel" and "mythological" nature of the output while maintaining professional utility.

## Success Metrics
- Ability to track a narrative's progress through all 18 nodes.
- Ease of configuring model routing for specific agents.
- Clear visualization of the Critic/Wordsmith revision loop.
